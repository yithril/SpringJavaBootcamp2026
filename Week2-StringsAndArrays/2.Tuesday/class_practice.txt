# Java UML to Class Worksheet

## Setup Instructions (Do This First)

1. Open IntelliJ
2. Create a new Java project inside your **Exercises** folder
3. Name the project:
   
   UMLClassPractice

4. Inside your `src` folder, create the following classes:
   - Student.java
   - Car.java
   - User.java

---

## Directions

For each UML diagram below:

- Create a Java class that matches the diagram exactly
- Use `private` for properties
- Generate **getters AND setters** for all properties
- Write the constructor(s) exactly as shown
- Do NOT add extra methods

---

## Example (Reference)

UML:

Book
------------------------
- title : String
- pages : int
------------------------
+ Book(title : String, pages : int)
+ getTitle() : String
+ setTitle(title : String) : void
+ getPages() : int

## Final Check (Before You Submit)

For each class, make sure:

- All properties are `private`
- You have **getters AND setters** for every property
- Constructors match the UML exactly
- Class names and file names match
- Code compiles without errors
